איך זה בנוי

הכל רץ בתוכנה אחת על המחשב בבית. שני מודלים של Claude עושים את העבודה: אחד לשיחה איתי, ואחד זול לקריאת הקבוצות ברקע.

שער ווטסאפBaileys. מעביר הלאה רק "הודעה לעצמי" עם /בוט והקבוצות שברשימה הלבנה. כל השאר נזרק מיד.
הסוכן הראשיClaude Sonnet 5.5. עונה בעברית ומשתמש בכלים: מערכת, ציונים, אימון, תזונה, יומן, משימות.
מנתח הקבוצותClaude Haiku 5.5. הופך הודעה בקבוצה לאירוע, תשלום, ציוד או הזמנה (JSON).
מחבר משו"במערכת, ביטולים, ציונים והתנהגויות. סורק כל 30–60 דקות.
מחבר שחףמערכת וביטולים, ממוזגים עם משו"ב.
מחבר יומן גוגלקורא את כל האירועים וכותב ליומן-המשנה "בוט".
מתזמןתדריך ב-07:15, תזכורות תשלום, התראות על ציונים חדשים.
מסד נתוניםSQLite, קובץ אחד מקומי על המחשב.
מה קורה כשאני שואל "/בוט מה התבטל היום?"
  1. שער הווטסאפ מזהה את הקידומת ומעביר את ההודעה לסוכן.
  2. הסוכן מפעיל את הכלי schedule.today(), שקורא מהמסד את מה שנשלף ממשו"ב ומשחף.
  3. הסוכן מנסח תשובה קצרה ושולח אותה ל"הודעה לעצמי".

התחברויות חד-פעמיות

ווטסאפ

  • מריצים את הבוט, וקוד QR מופיע בחלון.
  • בטלפון: מכשירים מקושרים ← קישור מכשיר ← סורקים.
  • npm run list-groups מציג את כל הקבוצות, ובוחרים את "צופים" ו"כושר קרבי".

יומן גוגל

  • יוצרים פרויקט ב-Google Cloud ומפעילים את Calendar API (בהדרכה).
  • npm run google-auth פותח קישור, ומאשרים.
  • הבוט יוצר יומן-משנה בשם "בוט".

משו"ב ושחף

  • שם המשתמש והסיסמה נשמרים בקובץ .env על המחשב בלבד.
  • נבדוק יחד את מבנה האתרים בשלבים 5 ו-6.

Claude API

  • נרשמים ב-console.anthropic.com ומוסיפים $5 של קרדיט.
  • יוצרים API key ושמים אותו ב-.env.
  • אם אני מתחת לגיל 18, הורה צריך לפתוח את החשבון.

שלבי הבנייה

כל שלב עובד ונבדק לפני שעוברים לבא. מתחילים ממה שבטוח יעבוד, ומשאירים את בתי הספר לסוף כי שם יש הכי הרבה אי-ודאות.

  1. שלד ו-Claude APIמבנה הפרויקט, מסד הנתונים, ופתיחת חשבון API בהדרכה.
  2. ווטסאפ וסוכן בסיסיQR, הקידומת /בוט, תשובות בעברית, זיכרון עובדות.
  3. אימונים ותזונהקליטת PDF וטקסט, "איזה אימון היום?", עדכונים בשיחה.
  4. יומן גוגלקריאת כל האירועים, יומן-משנה "בוט".
  5. קבוצותרשימה לבנה, מנתח Haiku, תשלומים, והוספה אוטומטית ליומן בלי כפילויות.
  6. משו"במערכת, ביטולים, ציונים, התנהגויות והתראות על כל דבר חדש.
  7. שחףמערכת וביטולים, ממוזגים עם משו"ב.
  8. תדריך ותזכורות07:15 כל יום, ותזכורות לתשלומים ולאירועים.
  9. הרצה קבועה בביתpm2, עלייה אוטומטית עם הדלקת המחשב, ביטול מצב שינה.

פרטיות וסיכונים

  • כל המידע נשמר על המחשב שלי. ל-Claude נשלח רק מה שצריך כדי לענות על שאלה מסוימת או לנתח הודעה מסוימת.
  • קבוצות שלא ברשימה הלבנה נזרקות לפני כל עיבוד, לא נשמרות ולא נשלחות לשום מקום.
  • סיסמאות, טוקנים וה-session של ווטסאפ נשמרים בתיקייה data/ ובקובץ .env, ולעולם לא עולים ל-GitHub.
חשוב לדעת: החיבור לווטסאפ ולמערכות בית הספר לא רשמי. ווטסאפ יכולה לנתק או לחסום, ומשו"ב או שחף יכולים לשנות את האתר. התוכנית מצמצמת את הסיכון, אבל לא מבטלת אותו.
