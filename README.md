## שלב 0: התקנה במחשב

צריך שיהיו מותקנים **Node.js 22** ([nodejs.org](https://nodejs.org)) ו-**Git**.

```bash
git pull                 # להוריד את הגרסה העדכנית
npm install              # להתקין את החבילות
cp .env.example .env     # ב-Windows: copy .env.example .env
npm start                # בדיקת מצב
```

`npm start` מציג מה כבר מחובר (✅) ומה עוד חסר (⬜).

## שלב 0: פתיחת חשבון Claude API

1. נכנסים ל-**console.anthropic.com** ונרשמים (אפשר עם חשבון Google).
   אם אתה מתחת לגיל 18, הורה צריך לפתוח את החשבון על שמו.
2. בתפריט: **Settings → Billing**, ומוסיפים קרדיט של **$5**. זה מספיק לשבועות של שימוש.
   מומלץ להגדיר שם גם **Spend limit** חודשי (למשל $10) כדי שלא יהיו הפתעות.
3. בתפריט: **API Keys → Create Key**. נותנים לו שם (למשל `self-agent`) ומעתיקים את המפתח.
   **המפתח מוצג רק פעם אחת**, אז מעתיקים אותו מיד.
4. פותחים את הקובץ `.env` ומדביקים:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
5. בודקים שהמפתח עובד:
   ```bash
   npm run check-claude
   ```
   אם מופיע `✅ Claude עובד` עם משפט בעברית, שלב 0 גמור.

> 🔒 לעולם לא לשלוח את המפתח לאף אחד ולא להדביק אותו בצ'אט. הקובץ `.env` והתיקייה `data/` לא עולים ל-GitHub.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm start` | מפעיל את הבוט. בדיקה: כותבים `/בוט פינג` ב"הודעה לעצמי" |
| `npm run dev` | כמו start, אבל מתאתחל אוטומטית כשקוד משתנה |
| `npm run check-claude` | בודק שמפתח ה-API עובד |
| `npm run list-groups` | מתחבר לווטסאפ (QR) ושומר את רשימת הקבוצות ב-`data/groups.txt` |
| `npm run typecheck` | בודק שאין שגיאות בקוד |
| `npm run db:generate` | יוצר מיגרציה אחרי שינוי ב-`src/db/schema.ts` |
